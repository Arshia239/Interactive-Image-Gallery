# 🖼️ Interactive Image Gallery

A responsive, filterable image gallery with a smooth lightbox viewer — built using vanilla HTML, CSS, and JavaScript. Browse images by category and view them full-screen with next/previous navigation.

🔗 **Live Demo:** (https://interactive-image-gallery-psi.vercel.app)

## ✨ Features

- 🗂️ **Category filtering** — switch between All, Nature, Architecture, and Animals
- 🔍 **Lightbox viewer** — click any image to view it full-screen
- ◀️▶️ **Next/Previous navigation** inside the lightbox
- ❌ Easy close with the on-screen close button
- 📱 Fully responsive grid layout for mobile, tablet, and desktop
- ⚡ Built with vanilla JavaScript — no frameworks, no dependencies

## 🛠️ Built With

- **HTML5** — structure and markup
- **CSS3** — responsive grid layout and styling
- **JavaScript** — filtering logic and lightbox interactivity
